# Module onetimesecret-kotlin

Official Kotlin SDK for the [Onetime Secret](https://onetimesecret.com) API v2,
for Android and the JVM.

Start with [com.onetimesecret.sdk.OnetimeSecretClient].

# Package com.onetimesecret.sdk

The client, its configuration, resource groups (`secrets`, `receipts`) and the
exception hierarchy.

# Package com.onetimesecret.sdk.model

Immutable data types returned by the API.
